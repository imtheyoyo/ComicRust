# Design de l'interface — à faire

Demande de Yoyo (24/10/2026) : refaire l'interface de ComicRust dans l'esprit de ces maquettes
([image](maquettes-nebula-chromatik-vectora.png)). Trois variantes de thème sombre :

- **Nebula BD** : sobre, violet/bleu nuit.
- **Chromatik** : sombre, couvertures mises en avant, accents roses/magenta, icônes colorées par genre.
- **Vectora** : technique, accents turquoise, statistiques et barres de progression de lecture.

Écrans communs aux trois :
1. **Bibliothèque** : barre latérale (Bibliothèque, Séries, Auteurs, Genres, Collections,
   Listes ; « Ma lecture » : À lire, En cours, Terminées ; Paramètres), recherche, grille de
   couvertures avec série et nombre de tomes.
2. **Navigation** : séries / auteurs / genres en liste avec vignette, compteur, progression.
3. **Filtres** : panneau latéral (statut de lecture, genres, auteurs, année de publication en
   curseur), boutons Appliquer / Réinitialiser.
4. **Lecture** : lecteur plein cadre, flèches de page, bande de vignettes, mode page ou case,
   zoom, compteur de pages.
