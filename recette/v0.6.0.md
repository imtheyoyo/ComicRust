## 0. Déjà vérifié automatiquement (pour information)

- **Écriture des infos** : ComicRust relit la fiche du livre dans la base au moment d'écrire
  (`SELECT data FROM comics WHERE id=…`). Il en garde les éléments de `ComicInfo`, dans l'ordre
  de la classe `ComicInfo` de ComicRack, et les écrit dans le `ComicInfo.xml` de l'archive.
  - Les champs propres à la bibliothèque (page lue, date d'ajout, note…) ne vont pas dans le fichier.
  - Les éléments inconnus de ComicRack déjà présents dans le fichier (ex. `GTIN`) sont gardés.
  - Un champ vidé dans ComicRack est effacé du fichier.
- **Archive réécrite sans risque** : copie brute des pages (sans recompression) dans
  `<fichier>.comicrust.tmp`, relue et vérifiée, puis remplacement de l'original. En cas
  d'erreur, l'original est intact et le fichier temporaire supprimé.
- **HEIF/AVIF** :
  - l'AVIF est décodé en pur Rust ; écart avec ffmpeg : 46 dB, c'est-à-dire invisible ;
  - le HEIC passe par le décodeur de Windows ;
  - sans les extensions Windows, le décodeur pur Rust de secours montre de petits défauts sur
    les zones très détaillées (33 dB face à libheif) : voir H-02.
- **WebComic** : portage de `WebComic.GetParsedImages` / `GetIndexScraperPages` /
  `GetBrowseScraperPages` et de la composition de `WebComicProvider`.

## Limites connues de la v0.6.0 (ne pas compter comme anomalies)

- **La base ComicRack n'est pas modifiée** :
  - ComicRack garde les livres écrits par ComicRust dans « Fichiers à mettre à jour » ;
  - la taille et la date de ces fichiers changent ; ComicRack s'en aperçoit à sa prochaine
    vérification, sans conséquence (le contenu est le même).
- **Conversion** :
  - le nouveau CBZ n'est pas dans la base ComicRack : il faut l'y ajouter (ComicRack le verra
    comme un nouveau livre, avec les infos du `ComicInfo.xml`) ;
  - si l'original est rangé, ComicRack le voit comme manquant ;
  - seules les pages et `ComicInfo.xml` sont repris (pas les autres fichiers de l'archive).
- Les infos ne s'écrivent que dans les CBZ (pas dans les CBR, PDF ou CBW).
- **WebComic** :
  - pas de cache entre deux ouvertures : chaque ouverture relit les pages web ;
  - un scraper de navigation s'arrête à 20 000 pages.
- **HEIC** :
  - sans les extensions Windows, le décodeur de secours est plus lent (≈ 1 s par grande
    page) et peut laisser de petits défauts ;
  - l'AVIF n'a pas besoin d'extension.
