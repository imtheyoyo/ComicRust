## 0. Déjà vérifié automatiquement (pour information)

A-03 n'a **pas pu être reproduit** dans l'atelier : avec MariaDB 10.11 et une base vide, l'assistant
crée les tables, analyse les échantillons et garde la configuration. Une fermeture sans aucun
message correspond à un arrêt brutal (le plus probable sous Windows : débordement de pile, qui ne
laisse aucune trace). La v0.7.1 :
- agrandit les piles (16 Mio pour tous les fils, 8 Mio pour le fil principal) ;
- écrit tout plantage dans `data\plantage.txt`, montré au lancement suivant ;
- enregistre les réglages dès la fin de l'assistant.

| Vérification | Où | Résultat |
|---|---|---|
