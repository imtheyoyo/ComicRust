## Limites connues de la v0.10.1 (ne pas compter comme anomalies)

- **Fenêtre d'infos** : pas d'onglets Pages ni Couleurs ; pas de mode « ajouter / retirer des
  valeurs » sur plusieurs livres comme ComicRack.
- **Bedetheque** : la couverture n'est pas remplacée dans le fichier ; le nombre de planches n'est
  pas écrit (nombre de pages en lecture seule) ; double-clic dans les listes = choisir.
- **Library Organizer** : le mode **Copier** fonctionne comme **Simuler** (ComicRust ne copie pas
  encore de fichiers) ; « remplacer » un doublon n'existe pas (ComicRust n'écrase jamais) ; les
  dossiers vides se suppriment par une commande à part, après le rangement.
- Les fichiers de test du site Bedetheque ont été reconstitués : si le site a changé, la recherche
  peut échouer (le dire dans le rapport, avec l'album essayé).
