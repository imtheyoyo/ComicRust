## 1. Préparation

- [ ] **P-01 [B]** Télécharger `ComicRust-v0.3.0-windows-x64.zip` depuis la [release v0.3.0](https://github.com/imtheyoyo/ComicRust/releases/tag/v0.3.0) et vérifier l'empreinte : `Get-FileHash .\ComicRust-v0.3.0-windows-x64.zip` → identique au SHA-256 ci-dessus.

## 6. Mise à jour intégrée

Il n'existe pas encore de version plus récente que la 0.3.0. Pour essayer l'installation complète,
la variable `COMICRUST_SIMULER_VERSION` fait croire à ComicRust qu'il est plus ancien : il propose
alors la v0.3.0 et la réinstalle par-dessus elle-même.

- [ ] **U-01 [B]** Menu ⚙ → « Rechercher une mise à jour… » → « ✔ Tu as la dernière version. »
- [ ] **U-02 [B]** Dans PowerShell, dans le dossier de ComicRust : `$env:COMICRUST_SIMULER_VERSION="0.2.0"; .\ComicRust.exe` → au démarrage, bandeau orange « ComicRust v0.3.0 est disponible » avec Installer / Nouveautés… / Plus tard / Ignorer cette version.
- [ ] **U-03 [M]** « Nouveautés… » : la fenêtre affiche « Mode recette : comparée aux releases comme v0.2.0 », les notes de la release et le lien vers GitHub.
- [ ] **U-04 [B]** « Installer » (ou « Télécharger et installer ») : barre de progression en Mo, puis « ✔ ComicRust v0.3.0 est installée » ; un fichier `ComicRust.exe.old` est apparu ; `data\` est intact (réglages, couvertures).
- [ ] **U-05 [B]** « Redémarrer maintenant » : ComicRust se ferme et se relance seul ; la base se recharge ; `ComicRust.exe.old` a disparu.
- [ ] **U-06 [M]** « Ignorer cette version » (avec la variable) : le bandeau ne revient plus aux lancements suivants pour la v0.3.0. « Plus tard » : il revient au lancement suivant.
- [ ] **U-07 [m]** Décocher « Vérifier les mises à jour au démarrage » (menu ⚙) : plus de bandeau au démarrage, même avec la variable ; la recherche manuelle fonctionne toujours.
- [ ] **U-08 [m]** Sans Internet (Wi-Fi coupé) : « Rechercher une mise à jour » affiche une erreur « GitHub injoignable… », sans bloquer l'application.

Fermer PowerShell après ces tests (la variable ne vaut que pour cette fenêtre).

## Limites connues de la v0.3.0 (ne pas compter comme anomalies)

- **Lecture seule** : les pages lues dans ComicRust ne sont pas renvoyées à ComicRack (ni note, ni « lu »).
- La base est chargée entièrement au démarrage ; pas encore de mise à jour en direct quand ComicRack modifie la base (bouton « Recharger »).
- Seule la base **MySQL** est lue ; une bibliothèque `ComicDB.xml` n'apparaît pas dans la vue Bibliothèque (elle sert toujours aux listes).
- Pas encore de panneau de détails, de tri au choix, ni des listes de ComicRack (listes intelligentes, dossiers).
- Couvertures : première page du fichier (la couverture choisie dans ComicRack n'est pas encore prise en compte).
- Toujours sans objet : scrapers WebComic, HEIF/AVIF, association de fichiers, exe non signé (SmartScreen peut prévenir au premier lancement d'une version installée par la mise à jour).
