## 1. Préparation et compatibilité

- [ ] **P-01 [B]** Ta v0.6.0 propose la v0.7.0 ; « Installer » puis « Redémarrer maintenant » → « ? » → **ComicRust 0.7.0**. Aucun assistant ne s'ouvre : ta bibliothèque ComicRack (MySQL) s'affiche comme avant, avec ses listes.
- [ ] **P-02 [B]** Menu ⚙ → « Assistant de configuration… » : la page « Avec ComicRack » montre ton `ComicRack.ini`, `ComicDb.xml` et `Config.xml` (« ✔ trouvé »), MySQL avec tes paramètres (le mot de passe n'est pas affiché). « Annuler » ne change rien.

## 2. ComicRust autonome (copie de ComicRust dans un autre dossier)

- [ ] **S-01 [B]** Dézipper le paquet v0.7.0 dans un nouveau dossier, lancer `ComicRust.exe` : l'assistant « Bienvenue dans ComicRust » propose « ComicRust autonome » et « Avec ComicRack ».
- [ ] **S-02 [B]** « ComicRust autonome » → « Fichier local » → ajouter un dossier de BD (taper `\\SERVEURNAS\…` puis « Ajouter », ou « Parcourir… ») — un sous-dossier d'une centaine de BD pour commencer — → « Terminer » : la bibliothèque se remplit, la barre d'état montre « Analyse des dossiers : n / total », puis le bilan. `data\comicrust.db` existe à côté de l'exe.
- [ ] **S-03 [B]** Les livres ont leurs infos (série, numéro, titre, auteurs, couverture) lues dans leur `ComicInfo.xml` ; tri, groupes, piles, recherche, fiche fonctionnent.
- [ ] **S-04 [B]** Lire quelques pages d'un livre, « ✖ Fermer » : barre orange et « Lu : x % (page n) » dans la fiche. Fermer ComicRust puis le relancer : la lecture est gardée, le livre se rouvre à la bonne page.
- [ ] **S-05 [M]** Relancer : l'analyse du démarrage ne rajoute rien (« 0 ajoutés »). Ajouter un CBZ dans le dossier, « 🔍 Analyser les dossiers » : il apparaît. Le supprimer (ou le déplacer hors du dossier), analyser : il est compté « manquant ».
- [ ] **S-06 [M]** Modifier un livre avec ComicRack ou ComicTagger (son `ComicInfo.xml`), analyser : la fiche est relue (« mis à jour »), la lecture du livre est gardée.
- [ ] **S-07 [M]** Clic droit sur un CBR → « Convertir en CBZ » avec « Ranger l'original » : le livre pointe sur le CBZ (fiche, ouverture), sa lecture est gardée ; l'analyse suivante ne crée pas de doublon.
- [ ] **S-08 [m]** « 📋 » à côté de « Analyser » : bilan de la dernière analyse, copiable (fichiers illisibles listés).
- [ ] **S-09 [m]** Lire quelques pages puis fermer directement la fenêtre de ComicRust (croix) : à la relance, la page est gardée.

## Limites connues de la v0.7.0 (ne pas compter comme anomalies)

- **Mode autonome** :
  - pas encore de listes (v0.9.0) ;
  - pas encore de modification des fiches dans ComicRust : les infos viennent des `ComicInfo.xml` ;
  - les dossiers d'images ne sont pas ajoutés à la bibliothèque.
- **Transfert de la base ComicRack** (lectures, notes, listes) vers la base de ComicRust :
  v0.8.0. D'ici là, une base autonome repart des fichiers (lectures de ComicRack non reprises).
- **Avec ComicRack** : lecture seule ; l'écriture dans la base de ComicRack arrive en v0.9.0.
  `Config.xml` est seulement repéré (pas encore lu).
- **Chemins des dossiers** : écrire un dossier toujours de la même façon (`\\SERVEURNAS\…` ou une
  lettre de lecteur, pas les deux) ; changer d'écriture ferait voir les fichiers comme nouveaux.
- **MySQL très ancien** (MySQL 5.5 / 5.6, MariaDB < 10.2) : possible refus de créer la table
  des livres si `innodb_strict_mode` est activé.
