## 0. Déjà vérifié automatiquement (pour information)

Cause trouvée grâce au rapport de plantage de la v0.7.1 :
- en passant de ta bibliothèque (4 941 livres) à la base MySQL neuve (0 livre), la barre d'état
  comptait les séries d'une présentation calculée pour l'ancienne bibliothèque ;
- dans l'atelier, les deux bibliothèques avaient le même nombre de livres : le défaut ne se
  montrait pas.

| Vérification | Où | Résultat |
|---|---|---|
| Changement vers une bibliothèque vide (chargement, ou `ComicDb.xml` relu) : plus aucun rang périmé | test `switching_to_an_empty_library_forgets_the_old_view` | ✅ |
| Reproduction : bibliothèque autonome SQLite de 13 livres → assistant → base MySQL vide et dossier vide → « Terminer » : pas de fermeture, « La base ne contient aucun livre », configuration gardée | capture | ✅ |
| 102 tests, clippy, rustfmt | CI Windows + Linux | ✅ |
