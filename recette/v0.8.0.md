## Limites connues de la v0.8.0 (ne pas compter comme anomalies)

- **Pas encore de création ni de modification de listes** dans ComicRust (v0.9.0) : les listes
  transférées s'affichent et se calculent.
- **Non repris de ComicRack** : le réglage des couleurs d'un livre (`ColorAdjustment`) et les
  couvertures personnalisées elles-mêmes (seule leur clé est gardée : l'image est dans le cache
  de ComicRack). Les listes intelligentes portant sur les signets ou les valeurs personnalisées
  ne sont toujours pas calculées.
- **Transfert relancé** : les fiches sont reprises de ComicRack. La lecture faite dans ComicRust
  et les fichiers convertis ou déplacés sont gardés, mais une fiche modifiée dans ComicRust
  serait remplacée (la modification des fiches arrive plus tard).
- **Listes** : relues dans la base toutes les 10 s si elles changent (transfert fait sur un
  autre poste partageant la même base MySQL).
- **Base ComicRust MySQL partagée** : après un transfert en v0.8.0, les ComicRust v0.7.x
  refusent cette base (schéma plus récent) ; mettre tous les postes en v0.8.0.
- Pour une destination MySQL : la configurer d'abord dans l'assistant (ComicRust autonome),
  puis la choisir comme « Base actuelle » dans la fenêtre de transfert.
