## 0. Déjà vérifié automatiquement (pour information)

Le mot de passe saisi dans l'assistant est chiffré avec la protection de données de Windows
(DPAPI, `CryptProtectData`), liée au compte Windows :
- il apparaît dans `comicrust.ron` sous la forme `dpapi:0100…` ;
- seul ton compte, sur ce PC, peut le relire.

## Limites connues de la v0.7.3 (ne pas compter comme anomalies)

- Le mot de passe est lié au compte Windows : sur un autre PC, il faut le saisir à nouveau (c'est
  voulu : le fichier copié ne suffit pas à se connecter).
- `ComicRack.ini`, fichier de ComicRack, garde lui-même le mot de passe en clair (ComicRust ne fait
  que le lire, il ne le recopie pas).
- Les copies de `comicrust.ron` faites avant la v0.7.3 (sauvegardes, autre dossier) contiennent
  encore le mot de passe en clair : à supprimer, ou changer le mot de passe MySQL si elles ont pu
  être lues par d'autres.
