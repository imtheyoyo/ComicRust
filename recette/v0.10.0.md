- [ ] **S-01 [B]** Sélectionner quelques livres, clic droit → **Scripts ▸** « Nettoyer les fiches » : la fenêtre d'exécution montre l'avancement puis l'**aperçu** (livre / champ / avant → après). « Annuler » : rien ne change.
- [ ] **S-02 [B]** Relancer, décocher un livre dans l'aperçu, « Appliquer » : seuls les livres cochés sont modifiés (fiche) ; bilan affiché. Fermer et relancer : les modifications sont gardées.
- [ ] **S-03 [B]** Sur 3 BD **copiées dans un dossier de test** : « Ranger les fichiers » (Réglages… : modèle de nom, sous-dossiers par série) : l'aperçu montre ancien → nouveau chemin ; « Appliquer » : les fichiers sont renommés/rangés, les livres s'ouvrent toujours, « Analyser les dossiers » ne signale ni manquant ni nouveau.
- [ ] **S-04 [M]** Relancer « Ranger les fichiers » sur les mêmes livres : aperçu vide (rien à renommer). Préparer un conflit (un fichier existant au nom visé) : il est signalé dans l'aperçu et **pas** appliqué ; aucun fichier n'est écrasé.
- [ ] **S-05 [M]** Pendant un script long (ex. « Nettoyer » sur toute la bibliothèque par 📜 Scripts), « Arrêter » : le script s'arrête ; le bouton « Voir l'aperçu de ces modifications » propose ce qui a déjà été demandé, rien n'est appliqué d'office.

## Limites connues de la v0.10.0 (ne pas compter comme anomalies)

- **Pas encore de fenêtre de modification des fiches** à la main dans ComicRust : les fiches se
  modifient par les scripts.
- **Scripts de ComicRack** (IronPython) : non compatibles, ce sont de nouveaux scripts Python.
- **Modules Python** : bibliothèque standard seulement ; un module pur Python peut être copié dans
  `scripts\lib\` (pip non disponible par défaut, voir `scripts.md`).
- **Renommages en chaîne** dans un même lot (A prend le nom libéré par B) : signalés comme conflit.
- **Comic Vine** : les endpoints suivent l'API connue (documentation officielle non consultée
  ici) ; limite de requêtes de Comic Vine respectée par une pause entre les requêtes.
- **ComicRack lancé** : il réécrit lui-même les fiches qu'il relit (sans effet sur le contenu).
